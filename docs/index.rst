OrbitDet
========

Orbit determination and astrodynamics toolkit.

The API reference is generated from the docstrings in ``src/orbitdet``.  Modules
whose docstrings contain ``.. math::`` directives render through MathJax, so
equations appear as typeset math rather than raw LaTeX.

``docs/api/`` is regenerated on every build by ``scripts/build_docs.sh`` - edit
the source docstrings, not those ``.rst`` stubs.
